# a02-illustrative: ILLUSTRATIVE carriers for High Press Escape (TEST-ONLY)

Stage W4 of the A02 package, 11 November 2026. Christian's second reply received 11 November 2026 delegates "Testing legitimate
configuration alternatives using clearly labeled provisional or illustrative knowledge." This folder holds one file of ours,
`a02-illustrative.DRAFT.json`. Nothing in it is knowledge, a restatement, a design or an authorization: every value is ours, labelled
ILLUSTRATIVE, and stands for what an approved answer of Christian's must supply. The register says a begin-condition referent is written
only by a ruled restatement (C58), so nothing here is one.

How it is read: only by `draft-store.ts` `loadIllustrativeCarriers` (a TEST-ONLY module no production module imports), held to its gate and
refused whole on any defect (OWNER_RULING refused by name; only AUTHORED, so a carrier establishes what it illustrates; no source claimed;
evidence beginning 'ILLUSTRATIVE'; no id, offset or geometric value copied from A01's provisional realization; episode scopes named
'ILLUSTRATIVE_...' and not in the register). Every item and declaration admitted is stamped with the category ILLUSTRATIVE. A case adds
groups only by a declared TEST-ONLY treatment (ILLUSTRATIVE_CARRIERS), on the chain's copy of the A02 draft store; the episode scope goes
only to a TEST-ONLY copy of the register for that build. The a02-composition store reads exactly what it read before.
