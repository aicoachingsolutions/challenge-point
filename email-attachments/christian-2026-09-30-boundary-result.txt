PASS COMBINATION — AND THE GRADUAL/REVERSIBLE QUESTION ANSWERS ITSELF

Authored from your canonical intent across the existing dimensions:
TEAMMATE_ACTION, IMMEDIATE_AFTER_TRIGGER, GRADUAL, TRANSITION_DEPENDENT, ALL.

The conflict is not real, and the model is not forcing anything. They are one
value each on two different dimensions. "Updates progressively" is IE-D008
REVEAL_PROGRESSION, whose question is whether information becomes increasingly
specified through unfolding interaction. "When the count resets, the revealed
state resets with it" is IE-D011 STATE_DEPENDENCY, whose question is whether
availability depends on the current functional state — and a reset is a
detectable transition that changes what is worth doing, which is IE-D011's own
integrity condition.

Recording the reset as IE-D008 REVERSIBLE would in fact VIOLATE IE-D008's
integrity condition, which requires later information to "refine rather than
arbitrarily overturn the task". A reset overturns it. So no representation change
is needed, and REVERSIBLE would have been the wrong home.
