# Ecological Integrity Review — Comprehensive Test Report

**Reviewer:** Ecological Integrity Review Layer v1.0.0
**Reviewed:** Production system as of 2026-05-17
**Inputs reviewed:** Five coach learning goals tested during the Phase 1 development cycle, three activities each (15 activities total).

---

## How to read this document

This report describes observable interaction properties in the activities the deterministic curriculum engine produced for each test input. It is not a pass/fail determination, and the findings do not represent ecological correctness ratings.

For each input the review layer examined three activities — Slot 1 (entry-level establish), Slot 2 (apply pressure), Slot 3 (full contest) — across the six integrity dimensions specified in the Operational Guardrails v1 directive: Constraint, Opposition, Decision, Representativeness, Incentive, and Scaling.

Each finding is observational. Interpretive sentences use probabilistic verbs (`may`, `likely`, `appears to`) per the spec. Factual quotes from the activity text are stated plainly; interpretation of those facts is always probabilistic.

The "Cross-category observations" section per test summarizes patterns visible only when the six per-category findings are viewed together.

# Cross-test observations

## Patterns visible across all five test inputs

**1. Decision Integrity is uniformly strong.** Across 15 activities, every Slot 3 surfaces 6+ decision-stem references in the bundle. Objectives consistently frame the activity as a read-and-decide problem. Priority 6 archetype-specific decision cues appear in coachingFocus for every test, naming the perceptual variables specific to that game form.

**2. Opposition Integrity is uniformly strong.** Every test produces a bidirectional teams description and an exchange rule that names opponent action on misread. Opposition vocabulary density ranges from 8–12+ hits per activity bundle. The deterministic mechanics builder reliably produces two-sided contest framing.

**3. Constraint Integrity is uniformly strong.** No prescriptive phrases ("must pass", "must shoot", "only use", "always X") detected in any of the 15 activities. Constraint descriptions consistently reference environmental shaping (zones, channels, areas, time windows) rather than behavior prescription.

**4. Representativeness Integrity is uniformly strong.** Each activity preserves directional consequence ("opponent inherits / gains / attacks" on misread). Named informational variables are dense and specific to the selected archetype.

**5. Incentive Integrity is uniformly strong on the conditional-scoring axis** — every activity uses "counts only when …" or "live advantage" framing. The recurring tradeoff is that scoring text references attacking outcomes more than reciprocal defensive outcomes, which may reduce defenders' visible stake in the reward structure.

**6. Scaling Integrity is the only dimension with consistent tradeoff flags.** Across all five tests, the setup field's specificity is the most visible gap. Field dimensions and numerical structures are typically not surfaced in coach-facing setup. Test 5 (Finishing) shows the strongest setup quality and the only setup that varies across slots; the other four tests have more generic setup paragraphs.

## Specific observations Christian may want to inspect

- **Test 4 (Defending counterattack with overloaded numbers):** The coach explicitly asked for a numerical overload scenario, and that numerical asymmetry does not surface in coach-facing setup or teams. The Transition Games archetype supports the structure, but a coach reading the output would need to invent the specific numbers.
- **Test 2 (Pressing & Regain):** The Counter-Press Window constraint has a defined time-window parameter (typical: 5 seconds), but the concrete time value does not surface in coach-facing setup. The constraint is named but its parameter is invisible to the coach.
- **All tests:** Scoring text references attacking outcomes (point, goal, score) more often than reciprocal defensive outcomes. Defensive success (regains, denials, recoveries) is supported via the lens content but not always anchored in the scoring rule itself.

## Limits of this review

- The review is deterministic text-pattern analysis. It cannot evaluate aspects of the activities that are not expressed in text — for example, how players actually behave under the activity.
- Pattern dictionaries are curated and incomplete by design. Missing markers do not mean the dimension is absent; only that the layer did not detect a signal for it.
- Probabilistic language ("may", "likely", "appears to") is observational, not safety glass. A finding that says "may reduce visibility" is an observation worth investigating, not a determination.
